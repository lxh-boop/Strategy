# 术语盲区：部署拓扑词汇（实例/进程）需要显式定义

用户对进程内代码概念（缓存、并发闸、限流）理解扎实，但部署词汇不牢：把"两个不同的用户"误当作"两个实例"——首课"两个实例"的对照因此没有落在正确的画面上。实际关系：20 个用户 = 1 个实例里的多个会话；实例 = 服务程序的一次运行（一个进程）。

Evidence: 2026-10-31 课后追问"实例是什么意思，两个不同的用户是两个实例吗"。
Implications: 后续课程凡涉及部署/运维词汇（实例、水平扩容、sticky session、负载均衡）先用 glossary 短定义锚定再展开；讲多实例演进时配部署拓扑示意；"进程内 vs 跨进程"仍是这位学习者最可靠的理解杠杆，但举例必须把"谁连谁"画清楚。
