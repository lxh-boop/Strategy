# Redis Resources

## Knowledge

- [Redis 官方文档：Data types](https://redis.io/docs/latest/develop/data-types)
  数据类型官方总览，每种带教程与命令参考链接。Use for: 每课知识主干；先读总览页，再进单类型页。
- [Redis 命令参考](https://redis.io/docs/latest/commands/)
  全量命令字典，按数据类型/用途分组，含时间复杂度与版本信息。Use for: 查语法、确认命令行为的第一站。
- [Redis Sandbox（官方浏览器沙盒）](https://redis.io/try/sandbox)
  免安装免注册的在线 Redis 控制台。Use for: 所有动手练习（Windows 本地装 Redis 麻烦，前期统一用它）。
- [Redis University（官方免费课程）](https://university.redis.io)
  官方自定进度课程，RU101《Introduction to Redis》为入门主线，含视频 + 实验 + quiz。Use for: 想系统过一遍时的课外主线。
- [node-redis 客户端文档](https://redis.io/docs/latest/develop/clients/nodejs)
  官方 Node.js/TypeScript 客户端。Use for: 把练习落回本项目代码形态时。
- [BullMQ 文档](https://docs.bullmq.io/)
  基于 Redis 的 Node 任务队列，《并发治理方案》点名的多实例演进件。Use for: 后期"任务队列"阶段；前期不需要。
- Book: _Redis in Action_（Josiah Carlson, Manning 2013）
  数据结构使用模式仍经典，但命令偏老（Redis 2.x 时代）。Use for: 深挖数据结构设计思想时的补充；命令一律以官方文档为准。

## Wisdom (Communities)

- [r/redis](https://www.reddit.com/r/redis/)
  官方 subreddit，信噪比高。Use for: 生产踩坑问题、方案评审要第二意见时。
