## 七、风险与注意

1. **红涨 = 品牌红**：主按钮、激活态、正收益数字同为 `#d93a3f`——这是策略商城已在生产验证的取舍（A 股语境红即涨即品牌），无需避讳；错误深红用 `#c62828` 区分。
2. `color-scheme: light` 翻转后原生控件（下拉/日历/滚动条）全变浅，`plain-select option` 的深底防白字补丁（`global.css:377`）可删。
3. 对比度已验：`#1f2329`/白 16.1:1，`#5c6470`/白 6.3:1，`#6b7280`/白 4.8:1，`#bd2f34`/白 6.2:1，`#1b7a45`/白 5.6:1——全部达标。
4. 实施面极小：令牌层集中 `:root`，组件零结构改动；硬编码清查表是全部附带工作量。
