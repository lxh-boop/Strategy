# 不卖条件保护全部卖出规则与调仓换出，不保护择时减仓；被保股同权调平

Status: accepted（2026-10-17 拍板，未实施）

果仁 tooltip 只说"不卖条件优先级高于卖出条件"，保护范围无一手细节；而本引擎里排名跌出（rank_out）本身就是 sellRules 之一，调仓换出（不在新目标集）又是另一条独立路径，"只对抗卖出规则"的字面读法会导出三种不同矩阵。决定：字段类卖出规则与调仓换出均受不卖条件保护，择时减仓（含调仓日目标市值降档）不受；被保住的持仓在调仓日按目标仓位同权调平、视同正式成员。理由：不卖语义="个股该不该离开组合"的规则全被压住，而择时是组合级仓位管理，不受单票意志影响；这也正是该功能的主用例（如"涨停不卖"防强势股被调出）。

## Considered Options

- **只保护字段类卖出规则**（功能清单初稿窄读）：否决——对纯排序策略（无卖出规则）几乎无用，功能失去主场景。
- **只保护调仓换出**：否决——"不管是否满足卖出条件"是果仁 tooltip 明说的事，砍掉止盈止损保护反而违背原文。
- **被保股权重冻结、不参与调平**：否决——造出"半退出现役"的中间态权重，破坏持仓等权语义。
