# 排除时间段采用冻结估值口径：段内净值走平、信号停算、挂起指令丢弃

Status: accepted（2026-10-17 拍板，未实施）

回测要支持剔除指定区间（如剔除股灾样本、只考察部分时段）。决定：排除段内不产生任何交易与信号，进入排除段时丢弃已挂起的卖出与调仓指令，解冻后不补调仓、等下一个自然调仓日；持仓按期初冻结价估值（不喂新价，走停牌回落估值机制），净值在排除段走平；收益等指标仍按全序列计算。这样"剔除"才真实成立——排除段的行情涨跌不进收益；若段内照市价估值，持仓照跌，剔除只挡住交易风险、挡不住持仓风险，名存实亡。第一批只做 v3 日频引擎，模型Ⅱ触发引擎同语义为跟进项。

## Considered Options

- **段内照市价估值、只停交易**：否决——同上，剔除目的落空。
- **信号照算、指令跳过**（功能清单初稿措辞）：否决——段内算出的信号没有任何出口，纯浪费；且不丢弃挂起指令的话，解冻首日会补执行一段过期调仓（主循环 pendingRebalance 重置点是现成的坑）。
- **解冻首日立即补一次到期调仓**：否决——与"该段历史当它不存在"的意图相反，还要给调仓日历加补位逻辑。
