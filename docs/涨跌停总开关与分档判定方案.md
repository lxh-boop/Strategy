# 涨跌停总开关与分档判定方案

日期：2026-10-22 ｜ 状态：**已实施（2026-10-22 当日，全量 283 测试绿+真库冒烟通过）** ｜ 关联：ADR-0009（修订 ADR-0008 默认值）、GLOSSARY「涨跌停判定」

## 1. 现状问题

1. **三状态并存**：涨跌停判定散在 9 处调用点，语义互相矛盾——
   - 挂开关（`limitUpDownSkip=true` 才判）：卖出规则清仓（strategy-backtest.service.impl.ts:662）、择时缩放块（682-689）、调仓新买（756）；
   - 判了但不看开关：b1 调仓卖出/排名跌出（744，无条件跌停顺延）；
   - 完全没判：b3 调仓补仓/减持（777-784）；触发引擎三处（trigger-backtest.service.impl.ts:304/321/340-347）无条件判、无参数。
   后果：开关开了 b3 不理、开关关了 b1 与触发引擎自作主张；默认行为不是完整掘金对齐。
2. **比率容差口径漏判**：±9.99% 一刀切（strategy-backtest.service.ts:255-258）。昨收 3.02 元的主板股真实涨停价 round(3.02×1.1,2)=3.32 元（+9.93%<9.99%），引擎误判可买；ST ±5% 档容差误差占比翻倍，低价 ST 股误放行最多。
3. **档位拍平**：不分 ST ±5%、创业板/科创板 ±20%、北交所 ±30%。

## 3. 功能清单（行为规格）

- **F1 全局总开关**：`limitUpDownSkip` 缺省 `true`。开启=引擎内所有买卖动作过涨跌停闸；关闭=全路径照常成交（掘金对照模式）。
- **F2 全路径覆盖**（9 处，行为统一）：主引擎 a 卖出规则清仓 / a′ 择时缩放回补与减仓 / b1 调仓卖出与排名跌出 / b2 调仓新买 / b3 调仓补仓与减持；触发引擎 a 卖出指令 / b 触发买入 / c 偏离带再平衡。
- **F3 判定规则**：执行价 ≥ 当日涨停价 → 该笔买入不成交；执行价 ≤ 当日跌停价 → 该笔卖出不成交。涨停/跌停价 = 交易所官方价（自动含主板 ±10%、ST ±5%、创业板 ±20%、科创板 ±20%、北交所 ±30%）换算到前复权口径（§4）。
- **F4 缺行降级**：官方表无该股当日行（约 0.07% 以下）→ 该笔不判，计数进回测摘要。
- **F5 参数面**：tool-specs 描述重写（分档矩阵 + 缺省开 + off=对照模式）；两引擎 spec 同步；确认卡与回测摘要始终展示"涨跌停判定：开启/关闭"。
- **F6 明确不做**：新股上市初期特殊段（官方价即真实段价格，天然含首日情形）；创业板历史制度切换（官方价天然正确）；ST 事件表覆盖层（列为 v1.1 可选，见 §6）。

## 4. 数据路线

### 路线 A（推荐，已验证）：官方涨跌停价 mkt_limit + 复权换算

库内实况（2026-10-22 实连库验证）：`mkt_limit` 19,371,620 行（2007-01-03 ~ 2026-10-21），字段 TICKER_SYMBOL / EXCHANGE_CD / TRADE_DATE / **LIMIT_UP_PRICE / LIMIT_DOWN_PRICE**（decimal(9,3)，交易所官方价）/ PRE_CLOSE_PRICE 等；单日覆盖 XSHG 3,486 + XSHE 4,020 + XBEI 352（全市场零缺行、零 NULL）。抽查：920992（北交）≈ +30%、300750（创业）≈ +20%、ST 生效期内（000662/000488/000078）≈ +5%、主板 ≈ +10%，全部命中。

**换算链**（mkt_limit 是未复权价，引擎行情 mkt_equd_adj 是前复权）：

```
factor     = adjPreClose / rawPreClose        -- 同日唯一；rawPreClose 取自 mkt_equd（已验证与 mkt_limit.PRE_CLOSE_PRICE 逐分一致）
limitUpAdj = LIMIT_UP_PRICE   × factor
limitDownAdj = LIMIT_DOWN_PRICE × factor
判定：execPrice(前复权) ≥ limitUpAdj → 不可买；execPrice ≤ limitDownAdj → 不可卖
```

同日所有价格共用同一调整因子，换算在数学上等价于把执行价换回未复权再比官方价。历史样例验证：300750 于 2020-07-15 factor=0.5128（累计分红），换算后 237.55×0.5128=121.82 为复权口径涨停价。

覆盖率：2026-10-21 缺行 0/7,858；2016-06-08 缺行 2/2,965（0.07%）→ 走 F4 降级。

### 路线 B（备选，不推荐）：引擎内推导档位

板块由 ticker+exchange 推（QuoteRow 已有 XSHG/XSHE/XBEI）+ ST 状态走 `equ_inst_sstate`（90030 事件表，PARTY_STATE 1=撤销ST/2=实施ST，EFF_DATE 可做 PIT，3,981 行在库）+ 自算 round 价 + 自维护日历规则。否决理由：管线长（要接 ST PIT、修白名单错位）、rounding 与制度切换自担、600363 案例证明两源各有滞后不如用交易所官方口径。保留为 v1.1 增强（对 mkt_limit 做事件表覆盖修正）。

### 白名单说明

readQuoteSeries 是引擎批量取数通道（SQL 硬编码，非 LLM 工具路径），JOIN mkt_limit/mkt_equd 不涉及 tables.md 白名单。是否把 mkt_limit 登记进 LLM 可查白名单（表目录注入）是独立决定，本次不做。

## 6. 边界与已知残留

- **官方源 ST 滞后**：600363 于 2026-09-29 实施 ST，mkt_limit 至 2026-10-21 仍给 ±10%（抽查实证）。残留概率低但存在；v1.1 可选：equ_inst_sstate 事件窗口覆盖修正。
- **掘金对照**：对照跑必须两边显式对齐——引擎传 `limitUpDownSkip=false`（掘金侧无涨跌停逻辑，无参数可开）。
- **北交所可达性**：行情/因子/官方价全有；但 industry-engine 映射层只认 .SH/.SZ（industry-engine.ts:40-45），industries 参数筛不出北交票，securityIds 直传可达——不在本次范围。

## 7. 验收标准

1. 不传参默认跑：9 处路径全部过闸；显式传 false：9 处全部不判。
2. 抽查：涨停价开盘的买入被拒、跌停价卖出不成交、ST 股 ±5% 档生效、创业板 ±20% 档生效、北交所 ±30% 档生效。
3. 对照模式：引擎 off 与掘金同配置结果可比（涨跌停不再构成残差）。
4. 缺行降级计数与摘要一致；全量既有用例回归通过。
