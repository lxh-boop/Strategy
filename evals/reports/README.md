# evals/reports — 评测报告（scorecard 指标卡）

runner 每跑一轮输出一对同名 `.json`（机器可读）+ `.md`（人读），文件名 = 指标卡名 + 时间戳。历史报告只增不删，作为指标趋势的证据链。

```text
reports/
├── 指标卡-基线v1-*.json/.md            # 基线 v1（重命名后首份全量基线）
├── 指标卡-冒烟1/2/3-*.json/.md         # 测评套件搭建期的三轮冒烟
├── 指标卡-judge修复冒烟-*.json/.md     # judge 修复后的冒烟验证
└── 指标卡-cal13修正复测-*.json/.md     # cal-13 参数口径修正后的复测
```
