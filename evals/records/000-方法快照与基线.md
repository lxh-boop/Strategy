## 三、噪声纪律（所有改进项共用）

- 改进前后必须同 k、同任务集、同 judge 档位；
- 单任务 k=4 下 1 个 run 翻转 = ±25% 单任务波动；分类层面 ±10% 内视为噪声；
- run 级失败先看是否 LLM 降级重试痕迹（runner 已自动退避重试，残留降级会在卡里标注）。
