# Mission: 多实例部署（面试向）

## Why
用户要准备后端面试：把 Docker、Nginx/负载均衡、多实例发布与高可用这一块的八股题和场景排障题答扎实——讲得清原理、扛得住追问，并能用自己的 factor-agent 项目（NestJS + MySQL，规划中的单实例 → 多实例演进）讲出有细节的真实故事。动手实操退居为"让项目故事经得起追问"的支撑。（2026-11-02 由"亲手部署"转向，见 LR-0006）

## Success looks like
- 三课约 50 道高频题，每道能在 30 秒内口述要点，并接住 1–2 层追问
- 场景题能按「现象 → 排查 → 根因 → 解决 → 预防」作答（502/504、OOM、发布期报错、定时任务重复、限流失效……）
- 每课的"项目故事"能 1 分钟讲完且细节真实——前提是对应实操谱已亲手跑通
- 自评里"答上了"占比持续上升，超 7 天的题按时复习

## Constraints
- Windows 开发机；实操在 Docker Desktop 内完成
- 中文；答案贴合国内后端面试的常见问法
- 面试时间线未知——如有截止日期应补进来，用于排复习节奏

## Out of scope
- Kubernetes 深度运维——只到面试常问的概念层（Pod / Service / 探针 / 滚动策略）
- 云厂商控制台操作
- CI/CD 流水线搭建细节
