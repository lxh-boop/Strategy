# 精化：用户的部署心智模型 = 只有 Docker，容器外的世界是空白

用户追问"一台 nginx 是什么意思，不是使用 docker 部署吗"，并自述"在部署方面，我唯一知道的就是使用 docker 部署，其他的一点不懂"。结合 LR-0004 精化画像：用户掌握的是 **Docker 工具本身**（打包、跑容器——曾用 Docker 部署过前后端+DB），但**容器之外的部署语境接近零**：没有反向代理概念、不知道流量从哪进来、没接触过域名/端口暴露/云主机的分工。"一台 nginx"被理解成了一台独立的机器。

Evidence: 2026-10-31 两句原话（见上）；对"一台 nginx"的困惑。
Implications:
- LR-0004 的"Docker 基础不再教"只对了一半：**工具层**（docker run/镜像/容器）确实不用教，**部署语境层**（谁在访问服务、反向代理为何存在、端口/域名/入口）必须从零讲。
- 企业级漏斗/SLB/LVS/灰度等内容对当前阶段是噪音——全部推到 0005 以后；0002 必须先讲"流量从哪来"（浏览器→端口→容器直连 → 多实例后连谁 → 引出 nginx 容器），再进双实例实操。
- 核心教学锚点："Docker 是装程序的方式，不是程序的名单"——系统里除了你的 server 还有 nginx、redis 这些别人写好的程序，它们同样装进容器。
- 讲解纪律：任何新名词出现必须先回答"它是什么程序/谁在跑它"，再讲它干什么。
