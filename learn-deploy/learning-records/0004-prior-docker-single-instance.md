# 先验披露：用过 Docker（单实例全栈部署），多实例配合是空白

用户自述：不是完全新手——之前用 Docker 部署过前后端 + 数据库的全栈组合，但每个服务只跑过一个实例，从未做多实例配合（负载均衡、sticky、共享状态、扩缩容都没碰过）。

Evidence: 2026-10-31 用户原话"我之前用过 docker，部署过前后端和数据库，但是只有搞了一个实例，没进行多实例的配合"。

Status: superseded by LR-0005（本记录只对了一半——用户掌握的是 Docker 工具本身，容器外的部署语境接近零，见 LR-0005 的精化画像与教学纪律）。

Implications:
- Docker 基础（镜像/容器/分层、run/端口映射/卷、单容器管理）不再教，0001 里的对应段落降级为"速览/查阅"，教学重心全部压到多实例配合（§6 起）。
- 真正的新疆界清单：同镜像多容器、网关分流 + sticky、健康检查与滚动更新/零停机发布、compose 服务 DNS 与 --scale、多实例共享状态（→Redis 轨）、N 实例下的 DB 迁移向后兼容。
- Quiz 仍建议全做——检索练习对已会内容同样建立 storage strength。
- 与 Redis 轨 LR-0001（进程内缓存强项）拼起来：用户画像 = 单机单实例代码强、跨实例/部署拓扑空白——两轨课程正是补这一条缝。
