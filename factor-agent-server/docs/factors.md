# 因子知识库

> **用途**：本文档是"因子智投"智能体的因子知识**唯一数据源**。后端在每次构建智能体提示词时，
> 会自动读取本文档全文注入给大模型；`/api/factors` 接口下发给前端的因子库也应与本文档保持一致。
>
> **维护**：直接编辑本文件即可，保存后**下一次请求即生效，无需重启服务**（按文件修改时间自动重载）。
>
> ⚠️ **"短名"是模型调用 `select_factors` 工具时的标准入参**（工具 schema 与回测引擎都按短名引用），
> 改短名会导致模型传参错乱，请保持稳定；其他描述性内容可随意增改。

## 给模型的规则

1. 调用 `select_factors` 时，`factors[].name` **必须使用下文定义的"短名"**，禁止自创译名或英文名；
2. 权重为正数，**合计可以不为 100**（后端自动归一化，舍入残差补给最大权重项）；
3. 单个策略的因子数量建议 **2~5 个**：过少风格不稳定，过多互相稀释；
4. 用户没有明确给权重时，按因子对策略目标的重要性分配，参考各因子的"常用权重区间"；
5. 用户要求调整某个因子权重时，基于当前会话配置整体修改后重新传入全部因子。

## 因子定义

### 价值（value）
- 衡量指标：EP（盈利收益率）、BP（账面市值比）、股息率
- 投资逻辑：买入价格低于内在价值的股票，赚估值回归的钱
- 因子方向：得分越高 = 越"便宜"
- 常用权重区间：15% ~ 35%
- 风格定位：防御型 / 均衡型的底仓
- 注意：警惕"价值陷阱"——便宜可能反映基本面恶化，建议与质量因子搭配使用

### 成长（growth）
- 衡量指标：营收增速、净利润增速
- 投资逻辑：寻找盈利高增长的公司，赚业绩驱动市值扩张的钱
- 因子方向：得分越高 = 成长性越强
- 常用权重区间：25% ~ 45%
- 风格定位：进攻型 / 均衡型
- 注意：高成长股估值通常偏高，对盈利兑现敏感，适合搭配动量确认趋势

### 动量（momentum）
- 衡量指标：20 日 / 60 日相对强弱
- 投资逻辑：强势股短期延续强势（行为金融惯性效应）
- 因子方向：得分越高 = 近期走势越强
- 常用权重区间：20% ~ 45%
- 风格定位：进攻型核心
- 注意：动量策略换手高，对震荡市与急反转敏感，建议控制权重或搭配低波动对冲

### 质量（quality）
- 衡量指标：ROE、毛利率、经营现金流
- 投资逻辑：优选盈利能力强、盈利质量高的公司，长期复利更稳
- 因子方向：得分越高 = 盈利质量越好
- 常用权重区间：20% ~ 35%
- 风格定位：均衡型核心，防御型辅助
- 注意：质量因子是"压舱石"，与价值搭配可规避价值陷阱

### 低波动（lowvol）
- 衡量指标：波动率、特异波动
- 投资逻辑：低波动股票长期风险调整后收益更优（低波动异象）
- 因子方向：得分越高 = 波动越低
- 常用权重区间：20% ~ 35%
- 风格定位：防御型核心
- 注意：牛市后半段会明显跑输，属正常特性，勿因短期落后加大权重

### 股息率（dividend）
- 衡量指标：近 12 个月股息率
- 投资逻辑：高股息提供确定性现金回报与安全垫，熊市抗跌
- 因子方向：得分越高 = 股息回报越高
- 常用权重区间：20% ~ 40%
- 风格定位：防御型核心
- 注意：警惕"不可持续的高股息"（分红靠透支利润），建议搭配质量因子

### 流动性（liquidity）
- 衡量指标：换手率、成交额
- 投资逻辑：流动性好的股票交易冲击成本低，便于策略执行
- 因子方向：得分越高 = 流动性越好
- 常用权重区间：10% ~ 25%
- 风格定位：辅助因子，提升组合可交易性
- 注意：一般不作为主因子，避免组合风格被交易属性主导

### 小市值（size）
- 衡量指标：总市值、流通市值
- 投资逻辑：小市值股票弹性大、A股历史上存在规模溢价
- 因子方向：得分越高 = 市值越小
- 常用权重区间：20% ~ 30%
- 风格定位：进攻型辅助
- 注意：小市值风格波动剧烈，且极端行情下流动性风险大，须控制权重上限

### 情绪（sentiment）
- 衡量指标：北向资金流向、分析师评级变化
- 投资逻辑：资金与卖方共识领先或同步于价格，捕捉预期变化
- 因子方向：得分越高 = 市场情绪越好
- 常用权重区间：10% ~ 25%
- 风格定位：进攻型辅助
- 注意：情绪数据噪声大、衰减快，仅作增强，不宜重仓依赖

## 风格搭配参考

| 风格标签 | 因子侧重 | 说明 |
| --- | --- | --- |
| 进攻型 | 动量 + 小市值为主，可搭配流动性 / 情绪 | 追求收益弹性，回撤容忍度高 |
| 防御型 | 股息率 + 低波动为主，搭配价值 / 质量 | 追求稳健、回撤小，牛市弹性弱 |
| 均衡型 | 成长 + 质量 + 动量 | 收益与回撤平衡，适合大多数场景 |

## 与其他接口的一致性

- `/api/factors` 下发给前端的因子库（id + 名称 + 描述）应与本文档 9 个因子一一对应
  （对应关系：价值因子=价值、成长因子=成长、……、市值因子=小市值、情绪因子=情绪）；
- 选股筛选接口 `/api/screen` 的筛选字段（roe_ttm / pe_percentile 等）是**另一套字段体系**，
  与因子短名无关，不要在 `select_factors` 参数中使用。
