# mkt_idx_mf_new（指数资金流向(新)）字段描述

> 来源:通联离线数据字典 V1.6(自动导入自 CHM,照录原文)。

**表描述**:获取沪深指数日资金流向，包含资金净流入、资金流入、资金流出、小单资金流入、小单资金流出、小单资金净流入等；单类判断标准：以成分股前20个交易日平均每笔成交金额为参考值，对比每笔的成交金额，小单-（0-1倍]；中单-（1-10倍]；大单-（10-100倍]；超大单-大于100倍或金额大于100万；流入以正数计，流出以负数计。
