# mkt_idx_eval_ashare（沪深指数估值信息）字段描述

> 来源:通联离线数据字典 V1.6(自动导入自 CHM,照录原文)。

**表描述**:获取沪深指数估值信息，计算范围为成分股仅包含沪深股票的指数。包含市盈率、市净率、市现率、市销率、净资产收益率、指数总市值、流通市值、自由流通市值、换手率、自由流通换手率、股息率等信息。请注意：净利润与市值不含PE为负或大于1000的成分股；成分中含B股的，换算为CNY。
