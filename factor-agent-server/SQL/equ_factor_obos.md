# equ_factor_obos（股票因子_超买超卖型）因子字段描述

> 来源：通联离线数据字典 V1.6《通联量化因子库 V1.6》1.0_股票 / 1.0_424因子库。
> 表级说明见 [tables.md](tables.md)。
> 注：本表「中文名称/数据类型/可空」取自库表元数据（information_schema）；「字段描述」为按指标通用含义整理的说明文字，非字典原文——其中 SBM/STM/UpRVI/DownRVI 字典未提供算法说明，已如实标注。

**表描述**：这类因子由日 K 线价格序列运算得到，刻画股价的超买超卖与摆动状态，如乖离率、随机指标、相对强弱指标、价格动量与波动率等，反映短期价格偏离与反转特征，不依赖财报数据。
