# mkt_adjf（股票前复权因子）因子字段描述

> 来源：通联离线数据字典 V1.6《通联股票数据库 V1.6》1.0_股票行情 / 2.0_复权行情，字段描述均为字典原文。
> 表级说明见 [tables.md](tables.md)。

**表描述**：获取沪深京股票用来调整历史行情的前复权因子数据，包含除权除息日、除权除息事项具体数据、本次复权因子、累积复权因子以及对应的生效日期区间。该因子用来调整历史行情，不作为预测使用，于除权除息日进行计算调整。只在发生分红、配股、股改事件的除权除息日才有复权因子记录。
