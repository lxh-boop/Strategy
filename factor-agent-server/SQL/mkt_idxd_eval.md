# mkt_idxd_eval（指数估值信息）字段描述

> 来源:通联离线数据字典 V1.6(自动导入自 CHM,照录原文)。
> 表级说明见 [tables.md](tables.md)。

**表描述**:获取指数估值信息，包含指数总市值、流通市值、指数市盈率、指数市净率、ROE、成分股涨跌数等信息。请注意：净利润与市值不含PE为负或大于1000的成分股；成分中含B股的，换算为CNY。
