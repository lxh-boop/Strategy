# md_type（行业分类标准）字段描述

> 来源：通联离线数据字典 V1.6 《通联主表数据库 V1.6》4.0_其他辅助表 / 2.0_行业分类标准，字段描述均为字典原文。
> 表级说明见 [tables.md](tables.md)。

**表描述**：记录机构、证券与批文的多种分类目录汇总表，主要包括行业分类、证券类型分类、地域分类明细等。

## 字段信息

| 序号 | 字段名 | 中文名称 | 数据类型 | 可空 | 字段描述 | 备注 |
|---|---|---|---|---|---|---|
| 1 | ID | 自增ID | bigint | 否 |  |  |
| 2 | TYPE_ID | 分类ID | varchar(20) | 否 | 行业分类标准数字编码，010301-证监会行业V2012；010303-申万行业分类（2014版）；010321-申万行业分类（2021版）；010306-恒生行业；010314-中证行业分类（2016版）；010317-中信行业分类；010319-战略性新兴产业(2018)；010322-中证行业分类(2021)；010320-国证行业分类(2019) |  |
| 3 | TYPE_SYMBOL | 分类代码 | varchar(20) | 是 |  |  |
| 4 | TYPE_NAME | 分类名称 | varchar(50) | 否 |  |  |
| 5 | PARENT_ID | 父节点 | varchar(20) | 是 |  |  |
| 6 | POSITION | 排序 | tinyint | 是 |  |  |
| 7 | BEGIN_DATE | 起始日期 | date | 是 |  |  |
| 8 | END_DATE | 截止日期 | date | 是 |  |  |
| 9 | IS_NEW | 是否最新 | tinyint | 否 | CODE_TYPE_ID = 10007 |  |
| 10 | INDUSTRY | 所属行业分类标准 | varchar(50) | 是 |  |  |
| 11 | INDUSTRY_VERSION | 所属行业分类版本 | varchar(20) | 是 |  |  |
| 12 | INDUSTRY_LEVEL | 行业级别 | tinyint | 是 |  |  |
| 13 | UPDATE_TIME | 更新时间 | datetime | 否 |  |  |

- [1]TYPE_ID 为行业分类标准数字编码：010301-证监会行业V2012；010303-申万行业分类（2014版）；010321-申万行业分类（2021版）；010306-恒生行业；010314-中证行业分类（2016版）；010317-中信行业分类；010319-战略性新兴产业(2018)；010322-中证行业分类(2021)；010320-国证行业分类(2019)。
